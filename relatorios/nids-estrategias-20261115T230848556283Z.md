# Comparabilidade das estratégias de explicação: Random Forest

A conferência foi aprovada. Ela compara execuções do NIDS com o Random Forest que leram o mesmo arquivo do trecho `campanha`, uma por estratégia de explicação. Os termos seguem o [glossário](../docs/glossario.md).

| Classificador, explicador e extrator nas CPUs configuradas, em todas as execuções | aprovada |
| Arquivos de classificação idênticos | aprovada |
