# Verificação dos modelos congelados

Os modelos Random Forest e XGBoost reproduziram todas as classificações binárias dos 314.993 registros de teste após o carregamento em processos Python novos. Cada modelo recebeu as mesmas entradas usadas na avaliação final, na mesma ordem. A comparação utilizou as previsões salvas nessa avaliação. O termo modelo congelado segue a definição do [glossário](../docs/glossario.md).

## Resultado da comparação

| Modelo | Registros comparados | Classificações divergentes | Maior diferença absoluta entre probabilidades |
|---|---:|---:|---:|
| Random Forest | 314.993 | 0 | 3,3306690738754696 × 10⁻¹⁶ |
| XGBoost | 314.993 | 0 | 0 |

O critério exige igualdade exata das classes previstas. A comparação adicional das probabilidades usa tolerância absoluta de 10⁻¹² e tolerância relativa zero. As probabilidades do Random Forest apresentaram uma diferença numérica abaixo dessa tolerância, sem alterar nenhuma classificação. As probabilidades do XGBoost foram idênticas. Esses resultados verificam a reprodução da inferência dos modelos salvos.

O processo que coordenou a verificação iniciou um interpretador Python para cada modelo. Os identificadores desses processos e as versões efetivamente utilizadas constam no [registro da execução](../training-runs/frozen-models/20261111T181031847482Z/report.json). Foram usados Python 3.12.3, NumPy 2.5.4, scikit-learn 1.9.1, SciPy 1.18.1, joblib 1.6.0 e xgboost-cpu 3.4.1. As demais dependências estão fixadas no arquivo `requirements.txt` de cada pacote.

## Contrato e integridade dos artefatos

O Random Forest mantém 100 árvores, profundidade máxima 12 e mínimo de dois registros por folha. O XGBoost mantém 100 árvores, profundidade máxima 6 e taxa de aprendizagem 0,1. Os dois modelos foram treinados com 1.469.983 registros e usam as mesmas 80 entradas. Todos os parâmetros constam nos manifestos dos pacotes.

| XGBoost | `ed0b315b8aee00c1988a6fb28a69ea3a0fc4c901fdc59832b7a2d451f54ea1e7` |

Os hashes coincidem com os arquivos fixados antes da avaliação no teste. Os pacotes estão em [training-runs/frozen-models/20261111T181031847482Z/](../training-runs/frozen-models/20261111T181031847482Z/), nas pastas `random-forest` e `xgboost`. Cada `manifest.json` registra o modelo, os parâmetros, os nomes e a ordem dos atributos, as versões de biblioteca, o processamento das entradas e os hashes dos arquivos. O hash do manifesto de dados é `69b1ff4ad68e2465013bc0266324f615b4780092fe4d2fbe0ca53595c423f779`.

As entradas usam `float64`, sem normalização. Infinito positivo em `Flow Bytes/s` e `Flow Packets/s` recebe o valor -1. Outros valores não finitos são rejeitados. O classificador recebe somente os 80 atributos definidos no [dicionário](../docs/dicionario-atributos.md), excluindo rótulos, metadados e os comprimentos de cabeçalho removidos na preparação. A previsão é ataque quando P(ataque) > 0,5; em caso de empate, é benigno.

## Inferência de um fluxo

O primeiro registro do teste foi classificado isoladamente e comparado com sua previsão de referência. Sua origem é o arquivo de índice 0, `monday.csv`, registro de `id` 7, com rótulo original BENIGN. Os atributos estão em `example-flow.json`, em cada pacote.

| Modelo | Classe prevista | Probabilidade de ataque |
|---|---|---:|
| Random Forest | Benigno | 0,0029051260302770244 |
| XGBoost | Benigno | 0,00004123865801375359 |

A inferência individual usa o modelo e o contrato do pacote salvo, além dos atributos do fluxo. As chaves do JSON são ordenadas conforme o manifesto. A verificação rejeita atributos ausentes, atributos adicionais e valores incompatíveis com o processamento definido.

## Reprodução

A partir de `src/`, com o ambiente descrito no [README](../src/README.md), execute os comandos abaixo. O primeiro cria novos pacotes a partir dos modelos finais indicados em [configs/model-freezing.json](../configs/model-freezing.json). Os demais verificam e usam o pacote já registrado neste relatório.

```bash
python main.py congelar-modelos
python main.py verificar-modelo --artifact ../training-runs/frozen-models/20261111T181031847482Z/random-forest
python main.py verificar-modelo --artifact ../training-runs/frozen-models/20261111T181031847482Z/xgboost
python main.py classificar-fluxo --artifact ../training-runs/frozen-models/20261111T181031847482Z/random-forest --input ../training-runs/frozen-models/20261111T181031847482Z/random-forest/example-flow.json
python main.py classificar-fluxo --artifact ../training-runs/frozen-models/20261111T181031847482Z/xgboost --input ../training-runs/frozen-models/20261111T181031847482Z/xgboost/example-flow.json
```

O congelamento depende dos dados preparados e das execuções finais de treinamento. A verificação completa usa os arquivos `X_test.npy` e `origin_test.npy` dos dados preparados e as previsões de referência incluídas no pacote. A classificação individual exige apenas o pacote, o JSON do fluxo e o código de inferência no ambiente compatível. Os binários estão fora do Git e devem acompanhar seus manifestos quando os pacotes forem transferidos.
