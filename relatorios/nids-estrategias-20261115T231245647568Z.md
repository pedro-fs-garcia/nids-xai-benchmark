# Comparabilidade das estratégias de explicação: XGBoost

A conferência foi aprovada. Ela compara execuções do NIDS com o XGBoost que leram o mesmo arquivo do trecho `campanha`, uma por estratégia de explicação. Os termos seguem o [glossário](../docs/glossario.md).
