# Conferência da cópia 16 do trecho `campanha`: XGBoost

A conferência foi aprovada. Ela grava a cópia 16 do trecho com o `tcprewrite` 4.6.2, que troca cada um dos 1.661 endereços IPv4 do trecho pelo endereço da cópia, com a mesma biblioteca de edição que o `tcpreplay-edit` usa na rede emulada. O NIDS lê a cópia do arquivo, sem XAI, e cada fluxo, com os endereços de volta aos originais, é comparado com o fluxo da leitura do trecho original. O primeiro endereço da cópia é `100.64.224.0`.

| Situação | Fluxos |
|---|---:|
| No trecho original | 24.413 |
| Na cópia | 24.413 |
| Na cópia, com endereços da cópia | 24.403 |
| Na cópia, sem endereço IPv4 do trecho | 10 |
| Casados | 24.413 |
| Só no original | 0 |
| Só na cópia | 0 |
| Casados com as 80 entradas idênticas | 24.413 |
| Casados com previsão ou probabilidade diferente | 0 |

Os fluxos sem endereço IPv4 do trecho são os que o extrator forma de quadros que não são IPv4, como o ARP. A troca de endereços não os altera, e eles são comparados sem conversão.

| Verificação | Resultado |
|---|---|
| Todo fluxo com endereços do trecho pertence à cópia conferida | aprovada |
| Cada fluxo da cópia corresponde a um fluxo do trecho original, e vice-versa | aprovada |
| As 80 entradas de cada fluxo são idênticas às do fluxo original | aprovada |
| A probabilidade de ataque e a previsão de cada fluxo são idênticas às do fluxo original | aprovada |

```bash
cd src && python main.py nids-conferir-copia --modelo xgboost --trecho campanha --numero 16 --original ../training-runs/nids/arquivo/20261115T193003910074Z
```
