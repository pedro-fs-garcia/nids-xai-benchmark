# Comparabilidade das estratégias de explicação: XGBoost

A conferência foi aprovada. Ela compara execuções do NIDS com o XGBoost que leram o mesmo arquivo do trecho `validacao`, uma por estratégia de explicação. Os termos seguem o [glossário](../docs/glossario.md).

## Verificações

| Verificação | Resultado |
|---|---|
| Uma execução de cada estratégia, e de cada critério do Síncrono condicional | aprovada |
| Mesmas entradas fixas: configuração, modelo, TreeSHAP, extrator, tráfego, CPUs e versões | aprovada |
| Todas as execuções passaram nas próprias verificações | aprovada |
| Cada execução registra os tempos da sua estratégia | aprovada |
| Classificador, explicador e extrator nas CPUs configuradas, em todas as execuções | aprovada |
| Arquivos de classificação idênticos | aprovada |
| Mesmos fluxos recebidos, classificados e não classificáveis | aprovada |
| Assíncrono explica os mesmos fluxos que o Síncrono total, com as mesmas contribuições | aprovada |
| Síncrono condicional por probabilidade explica exatamente os fluxos que o critério seleciona, com as contribuições do Síncrono total | aprovada |
| Síncrono condicional por incerteza explica exatamente os fluxos que o critério seleciona, com as contribuições do Síncrono total | aprovada |
